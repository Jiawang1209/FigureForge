# Enrichment Bubble Summary

## Chart Type

faceted enrichment bubble plot

## Chart Type Chinese

分面富集气泡图

## Aliases

enrichment bubble, GO bubble, dot plot, 富集气泡图, GO气泡图, 点图

## Best For

Prioritizing enriched terms using effect ratio, significance, and item count.

## Best For Chinese

根据富集比例、显著性和条目数筛选富集术语。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It is not an observation from a real study and supports no scientific
claim. Seed 1106 defines the fixture design.

## Data Schema

- term: enrichment term label
- gene_ratio: finite non-negative ratio
- adjusted_p: adjusted probability greater than 0 and at most 1
- count: positive integer item count
- category: categorical ontology or pathway group

## Visual Encoding

Horizontal position encodes ratio, point size encodes count, color encodes
negative log adjusted probability, and facets encode category.

## ggplot Components

- `geom_point()`
- `facet_grid(scales = "free_y")`
- continuous size and color scales

## Required R Packages

- ggplot2

## Adaptation Notes

Map an already computed enrichment table. Record the upstream background,
multiple-testing method, and ratio definition outside this plotting script.

## Common Pitfalls

- Zero adjusted probabilities must be replaced upstream with a documented
  finite bound, not silently transformed.
- Long term labels require enough export width.
