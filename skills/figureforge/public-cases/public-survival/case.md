# Survival Curve With Confidence Interval

## Chart Type

survival step curve

## Chart Type Chinese

带置信区间的生存曲线

## Aliases

survival curve, Kaplan Meier, time to event, 生存曲线, 事件时间

## Best For

Displaying precomputed time-to-event survival estimates by group.

## Best For Chinese

展示不同组的预计算事件时间生存估计。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It represents no cohort and supports no scientific claim. Seed 1109
identifies this deterministic fixture.

## Data Schema

- group: categorical comparison group
- time: finite non-negative time
- survival: probability from 0 to 1
- lower, upper: confidence bounds from 0 to 1

## Visual Encoding

Step height encodes survival probability and ribbons encode supplied intervals.

## ggplot Components

- `geom_ribbon()`
- `geom_step()`
- fixed probability scale

## Required R Packages

- ggplot2

## Adaptation Notes

Supply survival estimates computed by an appropriate upstream model and record
censoring and interval methods separately.

## Common Pitfalls

- This plotting script does not fit a survival model.
- Bounds and curves must remain within zero and one.
