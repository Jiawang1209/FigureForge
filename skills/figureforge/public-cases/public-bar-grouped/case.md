# Grouped Response Bar Chart

## Chart Type

grouped bar chart

## Chart Type Chinese

分组柱状图

## Aliases

grouped bar, bar chart, condition comparison, 分组柱状图, 柱形图

## Best For

Comparing one numeric response across treatments and conditions.

## Best For Chinese

比较多个处理和条件下的数值响应。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It is not an observation from a real study and supports no scientific
claim. Seed 1101 defines the fixture design.

## Data Schema

- treatment: categorical treatment label
- response: finite non-negative numeric value
- condition: categorical grouping condition

## Visual Encoding

Bar height encodes response, x position encodes treatment, and fill encodes
condition.

## ggplot Components

- `geom_col(position = position_dodge())`
- explicit fill palette and zero-based response axis
- publication-readable minimal theme

## Required R Packages

- ggplot2

## Adaptation Notes

Map the primary category to `treatment`, the measurement to `response`, and
the comparison group to `condition`. Set factor order before rendering when
the scientific order differs from the input order.

## Common Pitfalls

- Do not imply uncertainty when the input contains only point estimates.
- Do not use stacked bars when between-condition comparison is the goal.
