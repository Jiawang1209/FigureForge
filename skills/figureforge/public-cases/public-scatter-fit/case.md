# Scatter Plot With Fitted Trend

## Chart Type

scatter plot with linear fit

## Chart Type Chinese

带线性拟合的散点图

## Aliases

scatter, regression, trend, 散点图, 拟合图, 回归趋势

## Best For

Showing association between two continuous variables with group context.

## Best For Chinese

展示两个连续变量之间的关联及其分组背景。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It is not an observation from a real study and supports no scientific
claim. Seed 1103 defines the fixture design.

## Data Schema

- predictor: finite numeric explanatory value
- response: finite numeric outcome value
- group: optional categorical group
- label: optional observation label

## Visual Encoding

Point position encodes predictor and response, color encodes group, and a
linear fit summarizes the overall trend.

## ggplot Components

- `geom_point()`
- `geom_smooth(method = "lm")`
- explicit color palette

## Required R Packages

- ggplot2

## Adaptation Notes

Map the explanatory variable to `predictor` and outcome to `response`. Confirm
that a linear summary is scientifically appropriate before retaining the fit.

## Common Pitfalls

- A fitted line does not establish causality.
- Strong group structure can make an overall fit misleading.
