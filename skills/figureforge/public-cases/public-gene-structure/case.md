# Gene Feature Structure Track

## Chart Type

gene structure and feature track

## Chart Type Chinese

基因结构与特征轨道图

## Aliases

gene structure, motif track, domain diagram, 基因结构, motif图, 结构域图

## Best For

Comparing ordered features along synthetic gene-like coordinates.

## Best For Chinese

比较合成基因坐标上的有序特征。

## Data Provenance

All coordinates were generated by FigureForge for demonstration and testing.
They represent no real gene and support no scientific claim. Seed 1111
identifies this deterministic fixture.

## Data Schema

- gene, feature: categorical track and feature
- start, end: finite non-negative coordinates with start below end
- strand: plus or minus orientation
- track: integer display row

## Visual Encoding

Horizontal position encodes coordinates, rectangles encode feature spans, and
fill encodes feature class.

## ggplot Components

- `geom_segment()` for backbones
- `geom_rect()` for features
- explicit aligned coordinate scale

## Required R Packages

- ggplot2

## Adaptation Notes

Normalize all coordinates to one declared coordinate system before plotting.

## Common Pitfalls

- Mixed coordinate conventions shift feature boundaries.
- Overlapping features require deliberate vertical layout.
