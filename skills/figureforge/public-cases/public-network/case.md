# Deterministic Node-Edge Network

## Chart Type

node-edge network

## Chart Type Chinese

节点边网络图

## Aliases

network graph, node edge, interaction network, 网络图, 节点边图

## Best For

Displaying a small known topology with reproducible supplied coordinates.

## Best For Chinese

使用可复现坐标展示小型已知关系网络。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It represents no real network and supports no scientific claim. Seed
1108 identifies this deterministic fixture.

## Data Schema

- record_type: `node` or `edge`
- node_id, node_label, x, y, group: node attributes
- source, target: edge endpoint IDs

## Visual Encoding

Segments encode edges, position encodes supplied layout, and color encodes node
group.

## ggplot Components

- `geom_segment()`
- `geom_point()` and `geom_text()`
- coordinate equality and deterministic layout

## Required R Packages

- ggplot2

## Adaptation Notes

Provide explicit node coordinates and ensure every edge endpoint exists.

## Common Pitfalls

- Layout geometry is descriptive and does not imply distance.
- Unknown endpoints must fail rather than create invisible edges.
