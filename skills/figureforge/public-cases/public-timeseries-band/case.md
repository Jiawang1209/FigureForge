# Time Series With Uncertainty Band

## Chart Type

longitudinal line chart with uncertainty

## Chart Type Chinese

带不确定性带的时序折线图

## Aliases

time series, line chart, confidence band, 时序图, 折线图, 置信带

## Best For

Comparing longitudinal estimates and their uncertainty across groups.

## Best For Chinese

比较不同组随时间变化的估计值及其不确定性。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It is not an observation from a real study and supports no scientific
claim. Seed 1104 defines the fixture design.

## Data Schema

- time: ordered numeric time coordinate
- estimate: finite numeric central estimate
- lower: finite lower interval bound
- upper: finite upper interval bound
- group: categorical trajectory group

## Visual Encoding

Line position encodes estimate and the translucent ribbon spans lower to upper.

## ggplot Components

- `geom_ribbon()`
- `geom_line()` and `geom_point()`
- group-aware ordering

## Required R Packages

- ggplot2

## Adaptation Notes

Map the time coordinate and precomputed interval bounds explicitly. Document
how uncertainty was calculated; this script does not infer intervals.

## Common Pitfalls

- Bounds must satisfy lower less than or equal to estimate and upper.
- Irregular time intervals must remain numeric or be parsed before plotting.
