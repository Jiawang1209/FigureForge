# Differential-Feature Volcano Plot

## Chart Type

volcano plot

## Chart Type Chinese

差异特征火山图

## Aliases

volcano plot, differential features, fold change, 火山图, 差异分析

## Best For

Screening features by effect size and adjusted significance.

## Best For Chinese

根据效应大小和校正显著性筛选差异特征。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It represents no real experiment and supports no scientific claim.
Seed 1107 identifies this deterministic fixture.

## Data Schema

- feature: unique feature identifier
- log2_fold_change: finite signed effect
- adjusted_p: finite probability greater than 0 and at most 1
- class: explicit significance class

## Visual Encoding

Position encodes effect and negative log probability; color encodes class.

## ggplot Components

- `geom_point()`
- horizontal and vertical threshold guides
- fixed semantic class palette

## Required R Packages

- ggplot2

## Adaptation Notes

Map an already computed differential table and document upstream thresholds.

## Common Pitfalls

- Do not infer classes silently from undocumented cutoffs.
- Zero probabilities require a documented finite bound upstream.
