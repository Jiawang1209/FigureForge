# Signed Correlation Heatmap

## Chart Type

correlation matrix heatmap

## Chart Type Chinese

相关性矩阵热图

## Aliases

correlation heatmap, matrix, tile plot, 相关性热图, 相关矩阵, 热图

## Best For

Summarizing signed pairwise associations among a small variable set.

## Best For Chinese

汇总少量变量之间有方向的两两关联。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It is not an observation from a real study and supports no scientific
claim. Seed 1105 defines the fixture design.

## Data Schema

- variable_x: categorical matrix column
- variable_y: categorical matrix row
- correlation: finite value from -1 to 1

## Visual Encoding

Diverging fill encodes sign and magnitude; text labels show the exact value.

## ggplot Components

- `geom_tile()`
- `geom_text()`
- fixed diverging scale from -1 to 1

## Required R Packages

- ggplot2

## Adaptation Notes

Supply long-form matrix data with one row per pair. Preserve the same variable
order on both axes when a symmetric matrix is intended.

## Common Pitfalls

- Values outside -1 to 1 are invalid correlations.
- Missing symmetric cells must be disclosed rather than silently mirrored.
