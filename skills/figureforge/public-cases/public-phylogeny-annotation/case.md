# Annotated Phylogeny Layout

## Chart Type

rectangular annotated phylogenetic tree

## Chart Type Chinese

带注释的矩形进化树

## Aliases

phylogenetic tree, tree annotation, cladogram, 进化树, 树注释

## Best For

Displaying a small supplied hierarchy with tip labels and clade groups.

## Best For Chinese

展示带叶标签和分支组的小型已知层级。

## Data Provenance

This hierarchy and its coordinates were generated by FigureForge for testing.
It represents no real taxa and supports no scientific claim. Seed 1110
identifies this deterministic fixture.

## Data Schema

- node, parent: unique node and parent identifiers
- x, y: supplied finite layout coordinates
- label, clade, is_tip: annotation fields

## Visual Encoding

Segments encode parent-child edges; tip color and text encode annotations.

## ggplot Components

- `geom_segment()`
- `geom_point()` and `geom_text()`
- deterministic supplied coordinates

## Required R Packages

- ggplot2

## Adaptation Notes

Prepare a rooted parent table and coordinates upstream; every non-root parent
must exist.

## Common Pitfalls

- This plot does not infer a tree or branch lengths.
- Missing parents and duplicate nodes must fail validation.
