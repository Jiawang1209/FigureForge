# Layered Distribution Comparison

## Chart Type

violin, box, and observation distribution

## Chart Type Chinese

小提琴箱线散点组合图

## Aliases

raincloud, violin plot, boxplot, 雨云图, 小提琴图, 箱线图

## Best For

Showing group shape, robust summaries, and individual observations together.

## Best For Chinese

同时比较组间分布形态、稳健汇总和单个观测。

## Data Provenance

This dataset was generated by FigureForge for demonstration and adaptation
testing. It is not an observation from a real study and supports no scientific
claim. Seed 1102 defines the fixture design.

## Data Schema

- group: categorical comparison group
- value: finite numeric observation
- sample_id: unique observation identifier

## Visual Encoding

Violin width encodes density, the box encodes quartiles, and jittered points
show observations.

## ggplot Components

- `geom_violin()`
- narrow `geom_boxplot()`
- deterministic `geom_point(position = position_jitter())`

## Required R Packages

- ggplot2

## Adaptation Notes

Map the grouping variable to `group`, observations to `value`, and retain a
unique `sample_id` for auditability.

## Common Pitfalls

- Very small groups cannot support a stable density estimate.
- Excessive jitter can imply values outside their real group.
