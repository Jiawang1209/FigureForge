# Changelog

## 1.0.1 - 2026-07-25

- Added an install-shaped `.agents/skills/figureforge` archive, packaged demo,
  manifest, SHA-256 sidecar, and strict archive/member verifier.
- Added portable Rscript resolution through `--rscript`,
  `FIGUREFORGE_RSCRIPT`, the compatibility path, and `PATH`.
- Added 3 authentic open-data public cases with source metadata, licenses,
  fixed upstream and normalized hashes, attribution, and human-verified QA;
  retained 12 synthetic demonstration cases.
- Added 30 deterministic bilingual forward evaluations and a bounded live
  Codex trigger gate; deterministic rows passed 30/30 and the release probes
  passed explicit 1/1 and implicit 10/10.
- Added v1.0.0-to-v1.0.1 atomic replacement coverage that preserves external
  adaptations and prevents stale installed files.
- Kept all private cases, source figures, reproductions, generated output, and
  raw live transcripts outside the public package.
- Kept the MCP Server planned and unimplemented.

## 1.0.0 - 2026-07-25

- Added 12 redistributable public visualization cases with synthetic data.
- Added 24 deterministic synthetic adaptation stress fixtures.
- Added protected external adaptation workspaces and schema matching.
- Added layered dependency diagnostics and bilingual public search.
- Added non-authoritative visual QA that keeps outputs at `review_required`.
- Added allowlist-based public packaging that excludes the private corpus,
  local indexes, rendered output, and reproduction assets.
- Kept the MCP Server planned and unimplemented.
